= 업그레이드 상태 점검 대시보드
:hardbreaks:
:allow-uri-read: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
 `runs/dashboard/index.html`에서 정적 HTML 대시보드가 모든 Upgrade Health Checker 실행이 끝날 때 생성됩니다. 대시보드는 최근 평가된 클러스터의 상태에 대한 개괄적인 개요를 제공하여 클러스터 간 업그레이드 준비 상태를 모니터링하고 비교할 수 있습니다.

나중에 대시보드를 다시 생성하려면(클러스터에 연결하지 않고) 다음을 실행하십시오.

[listing]
----
./uhc --dashboard
./uhc --dashboard --runs-path /custom/output
./uhc --dashboard --config-path /path/to/custom_config.yaml
----
다음은 최근 생성된 업그레이드 상태 점검 대시보드의 보기입니다. image:../media/dashboard3.gif[""]

페이지 상단에는 색상으로 구분된 5개의 요약 카드(각 카드는 선택 가능한 필터 역할도 함)가 있으며 다음과 같은 내용을 보여줍니다.

* *업그레이드 준비 완료:* 최근 상태 점검에서 차단 요소가 발견되지 않은 클러스터 수, 즉 업그레이드 준비가 완료된 클러스터 수입니다.
* *차단됨:* 차단된 클러스터 수이며, 차단 요인이 해결될 때까지 업그레이드할 수 없습니다.
* *오류:* 최근 UHC 실행이 완료되지 못한 클러스터 수(예: 연결, 인증 또는 데이터 수집 실패).
* *오래됨(>7):* 마지막 UHC 실행이 7일 이상 지난 클러스터 수(상태 점검 데이터가 오래됨).
* *플릿 총계:* 플릿에 있는 클러스터의 총 개수(대시보드 창에 실행 기록이 있는 클러스터 수, 기본값은 최근 30일).


Fleet 개요 섹션에서는 Fleet의 현재 상태에 대한 자세한 정보를 제공합니다. 각 클러스터에 대해 다음 정보가 제공됩니다(표는 클러스터별 최신 실행 결과를 보여줍니다):

* *클러스터 이름:* 클러스터 이름(이름 아래에 관리 IP가 표시됨).
* *상태:* 클러스터의 현재 상태: Ready, Blocked, Error 또는 Stale.
* *차단 요소:* 클러스터의 차단 요소 수입니다. 이는 업그레이드 전에 반드시 해결해야 하는 중요한 문제입니다.
* *위험 항목:* 클러스터에서 발견된 위험 항목 수입니다. 이는 업데이트 전 검사 중에 식별된 위험 요소입니다.
* *경고:* 클러스터의 경고 수입니다. 업데이트 전 검사가 일부 경고와 함께 완료되었습니다. 이러한 경고를 수정하거나 업데이트를 계속 진행할 수 있습니다.
* *건너뜀:* 클러스터에서 건너뛴 검사 수입니다.
* *대상 버전:* 사용자가 업그레이드하려는 ONTAP 버전입니다. (실행 중인 릴리스에 대한 상태 점검만 수행하려는 경우 현재 버전과 동일하게 지정할 수 있습니다.)
* *노드:* 클러스터의 노드는 각각 하드웨어 모델과 함께 노드 이름으로 표시됩니다(예: eurbkpcla(FAS8200)).
* *보고서:* 실행에 사용 가능한 보고서 형식: HTML, JSON, Excel, Log.
* *최근 실행:* 마지막 업그레이드 상태 점검 실행 날짜 및 시간(상대적인 "X일 전" 포함).


페이지를 새로고침하려면 *Reload*를 선택하세요. 특정 클러스터의 세부 정보를 검색하려면 *Search* 창을 사용하세요.
